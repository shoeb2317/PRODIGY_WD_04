## 📌 Project Overview

This repository contains **Task 04 (`PRODIGY_WD_04`)** completed as part of the **Prodigy InfoTech Web Development Internship**.

The goal of this task is to design, develop, and deploy an ultra-responsive, high-performance personal developer portfolio website to showcase software engineering skills, full-stack projects, academic qualifications, and contact channels.

---

## 🚀 Key Features

- **📱 Fully Responsive Layout**: Built with a mobile-first philosophy, utilizing modern CSS Grid and Flexbox for seamless viewing on mobile phones, tablets, laptops, and ultra-wide desktops.
- **🌓 Dynamic Dark / Light Themes**: Instant theme toggle with custom CSS variable tokens, smooth transitions, and persistent storage via `localStorage`.
- **✨ Glassmorphic Cyber Aesthetics**: Ambient glowing orbs, backdrop blur filters, and subtle micro-interactions for a premium look and feel.
- **⚡ Typing Hero Header**: Animated typing effect cycling through technical roles.
- **💼 Featured Projects Hub**: Detailed cards displaying live project snapshots, tech stacks, and source links:
  - *Lost & Found Portal* (Flask • SQLite • Web)
  - *Foundry ERP* (Enterprise Web Application)
  - *Academic Dashboard* (Full Stack Student Analytics)
- **📊 Comprehensive Skills Matrix**: Categorized grid for Frontend, Backend, Relational Databases, Core Languages (Java, Python, C++), and Developer Tools.
- **📄 Interactive CV & Contact Suite**:
  - Modal viewer for resume preview and download
  - One-click copy-to-clipboard for email and phone numbers with animated toast notifications
